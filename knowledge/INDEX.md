# Knowledge index

The starter knowledge the agent ships with: free, open sources, summarised with short quotes
and a link to each. Read this first in every review, then the work folder's
`05-knowledge/INDEX.md`, which holds your own sources and lessons. Open only the files that
apply. One line per file.

## Heuristics and guidelines

| File | What it holds |
| --- | --- |
| [effects/nng-10-usability-heuristics.md](effects/nng-10-usability-heuristics.md) | Nielsen's ten usability heuristics: visibility of status, match with the real world, control and freedom, consistency, error prevention, recognition over recall, flexibility, minimalist design, error recovery, help. |
| [effects/nng-icon-usability.md](effects/nng-icon-usability.md) | NN/g on icons: few are universal, labels must always be visible, the 5-second rule. |
| [effects/w3c-wcag22-selected.md](effects/w3c-wcag22-selected.md) | WCAG 2.2, partial: text alternatives, contrast, keyboard, time limits, interruptions, motion, status messages. |
| [effects/microsoft-human-ai-guidelines.md](effects/microsoft-human-ai-guidelines.md) | Amershi et al., 18 guidelines for human-AI interaction: what the AI can do, when to act, correcting it, how it changes over time. |
| [effects/govuk-service-standard.md](effects/govuk-service-standard.md) | GOV.UK Service Standard, points 1 to 5: understand users, solve a whole problem, join up channels, simple to use, everyone can use it. |
